# SocoPlay

SocoPlay is a mobile-friendly, browser-based mini-game portal. It includes
Solitaire, Tile Shift, Flip Pairs, and Word Bloom, with progress saved only in
the player’s current browser.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Check the project

```bash
npm test
```

## Project principles

- No account is required to play.
- Game progress, favourites, and recently played games use device-local storage.
- Ads are reserved for unobtrusive positions outside game controls.
