# SocoPlay

SocoPlay is a mobile-friendly, browser-based mini-game portal. It includes
Solitaire, Spider Solitaire, 8-Ball Pool, 2048, Tower Stack, Chess, Asteroids,
Pac-Man, Sudoku, Checkers, and Neon Dash, with progress saved only in the
player’s current browser.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Check the project

```bash
npm test
```

## Project principles

- No account is required to play.
- Game progress, favourites, and recently played games use device-local storage.
- Ads are reserved for unobtrusive positions outside game controls.
